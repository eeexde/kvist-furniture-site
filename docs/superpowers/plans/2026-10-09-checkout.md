# KVIST Checkout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the decorative KVIST cart into a working demo shop: persistent cart, cart drawer, branded checkout page, and Stripe Payment Element payments in test mode only.

**Architecture:** A shared catalog (`src/data/products.js`) feeds a localStorage-backed cart store used by the landing page (fly-to-cart, drawer) and a new Vite page `checkout.html`. One Vercel Node function `api/create-payment-intent.js` prices the cart from the catalog and creates a Stripe PaymentIntent; in dev a Vite plugin serves the same function at `/api/*`. The checkout page mounts Stripe's Payment Element styled with KVIST tokens and handles return/success states itself.

**Tech Stack:** Vite 5 (multi-page), vanilla ES modules, GSAP 3 + Lenis (existing), `stripe` (Node SDK), `@stripe/stripe-js`, Vitest 2, Vercel Node functions.

**Spec:** `docs/superpowers/specs/2026-10-09-checkout-design.md`

## Global Constraints

- Stripe **test mode only**. Server refuses any `STRIPE_SECRET_KEY` not starting with `sk_test_` (503 "Sandbox only"); client refuses any `VITE_STRIPE_PUBLISHABLE_KEY` not starting with `pk_test_`.
- Secret key lives only in `process.env` on the server; `.env` and `.env.local` are gitignored. Only `VITE_`-prefixed vars reach the browser.
- Amount is computed on the server from `PRODUCTS`; any client-sent price is ignored.
- Prices in integer cents, USD. Display format: `$1,290` for whole dollars, `$58.50` otherwise.
- `MAX_QTY = 10` per line, `MAX_LINES = 20` per request.
- Delivery is always "Free".
- Landing-page design and animations unchanged except: cart counter persists across reloads, `+` buttons added to the 3 Loved cards, drawer added.
- Every animation has a reduced-motion path (`prefersReduced()` / `html.reduced`): no transforms, instant state changes.
- Hit targets ≥ 44px. Visible labels on every input. Focus never lost after an action.
- Code style follows the repo: 2-space indent, no semicolons, single quotes, short header comment per module, `$`/`$$` helpers from `src/js/utils.js`.
- `npm run dev -- --host 0.0.0.0` must keep working on the LAN with no extra tools.

## Review Focus

1. **Corrupt or stale localStorage** (unknown ids from an older catalog, string/negative/fractional qty, non-JSON) — cart loads with bad lines dropped, never throws. Pinned in Task 2 (`sanitizes stored data`).
2. **Displayed total ≠ charged amount** — the drawer/summary subtotal for a cart must equal what the API charges for that same cart. Pinned in Task 3 (`charges exactly the store subtotal`).
3. **Tampered API payloads** (price fields, string qty `"2"`, qty `1.5`, duplicate ids, unknown ids, non-array) — 400, never a PaymentIntent. Pinned in Task 3 (pricing + handler tests).
4. **Cart edited in another tab while checkout is open** — summary updates and the PaymentIntent is re-created for the new amount; empty cart switches to empty view. Pinned in Task 2 (`reload() picks up external writes and notifies`) and manual check in Task 8.
5. **Returning from Stripe / refreshing the result URL** — success shows again (not an empty cart page); a failed intent returns to the form with values prefilled and an error. Pinned in Task 6 (`resultView` tests) and manual check in Task 8.

// Cart state: [{ id, qty }] persisted to localStorage, with change listeners and cross-tab sync.
import { PRODUCTS, MAX_QTY, isProduct } from '../data/products.js'

export const STORAGE_KEY = 'kvist-cart'

/** Keep only known products with whole positive quantities; merge duplicates; cap at MAX_QTY. */
function sanitize(raw) {
  if (!Array.isArray(raw)) return []
  const merged = new Map()
  for (const line of raw) {
    if (!line || !isProduct(line.id)) continue
    const qty = line.qty
    if (!Number.isInteger(qty) || qty < 1) continue
    merged.set(line.id, Math.min(MAX_QTY, (merged.get(line.id) || 0) + qty))
  }
  return Array.from(merged, ([id, qty]) => ({ id, qty }))
}

export function createStore(storage) {
  const listeners = new Set()
  let items = load()

  function load() {
    try {
      const raw = storage && storage.getItem(STORAGE_KEY)
      return raw ? sanitize(JSON.parse(raw)) : []
    } catch {
      return []
    }
  }

  function commit(change) {
    try {
      if (storage) storage.setItem(STORAGE_KEY, JSON.stringify(items))
    } catch {
      /* private mode / quota: keep working in memory */
    }
    listeners.forEach((fn) => fn(change))
  }

  return {
    getItems: () => items.map((l) => ({ ...l })),
    count: () => items.reduce((n, l) => n + l.qty, 0),
    subtotal: () => items.reduce((sum, l) => sum + PRODUCTS[l.id].price * l.qty, 0),
    qtyOf: (id) => {
      const line = items.find((l) => l.id === id)
      return line ? line.qty : 0
    },

    add(id) {
      if (!isProduct(id)) return false
      const line = items.find((l) => l.id === id)
      if (line) {
        if (line.qty >= MAX_QTY) return false
        line.qty += 1
      } else {
        items.push({ id, qty: 1 })
      }
      commit({ type: 'add', id })
      return true
    },

    setQty(id, qty) {
      const i = items.findIndex((l) => l.id === id)
      const n = Math.floor(Number(qty))
      if (i < 0 || !Number.isFinite(n)) return
      if (n < 1) items.splice(i, 1)
      else items[i].qty = Math.min(MAX_QTY, n)
      commit({ type: 'set', id })
    },

    remove(id) {
      const before = items.length
      items = items.filter((l) => l.id !== id)
      if (items.length !== before) commit({ type: 'remove', id })
    },

    clear() {
      if (!items.length) return
      items = []
      commit({ type: 'clear' })
    },

    /** Re-read storage (another tab changed it) and notify without writing back. */
    reload() {
      items = load()
      listeners.forEach((fn) => fn({ type: 'sync' }))
    },

    onChange(fn) {
      listeners.add(fn)
      return () => listeners.delete(fn)
    },
  }
}

function browserStorage() {
  try {
    return window.localStorage
  } catch {
    return null
  }
}

const hasWindow = typeof window !== 'undefined'

export const cart = createStore(hasWindow ? browserStorage() : null)

if (hasWindow) {
  window.addEventListener('storage', (e) => {
    if (e.key === STORAGE_KEY || e.key === null) cart.reload()
  })
}
```

// Server-side cart pricing. Validates the client's [{ id, qty }] and prices it from the catalog;
// any price the client sends is ignored. `_lib` is not routed by Vercel.
import { PRODUCTS, MAX_QTY, MAX_LINES, isProduct } from '../../src/data/products.js'

export class PricingError extends Error {}

export function priceItems(items) {
  if (!Array.isArray(items) || items.length === 0) throw new PricingError('Cart is empty')
  if (items.length > MAX_LINES) throw new PricingError('Too many items')

  const seen = new Set()
  const lines = items.map((line) => {
    const id = line && line.id
    if (!isProduct(id)) throw new PricingError('Unknown product')
    if (seen.has(id)) throw new PricingError('Duplicate product')
    seen.add(id)
    const qty = line.qty
    if (!Number.isInteger(qty) || qty < 1 || qty > MAX_QTY) throw new PricingError('Invalid quantity')
    return { id, qty, unit: PRODUCTS[id].price }
  })

  const amount = lines.reduce((sum, l) => sum + l.unit * l.qty, 0)
  return { amount, lines }
}
```

// POST /api/create-payment-intent — prices the cart on the server and creates a Stripe
// PaymentIntent. Test mode only: live keys are refused.
import Stripe from 'stripe'
import { priceItems, PricingError } from './_lib/pricing.js'

const MAX_BODY = 10_000

async function readBody(req) {
  const b = req.body
  if (b !== undefined && b !== null) {
    if (Buffer.isBuffer(b)) return JSON.parse(b.toString('utf8') || '{}')
    if (typeof b === 'string') return JSON.parse(b || '{}')
    return b
  }
  const chunks = []
  let size = 0
  for await (const chunk of req) {
    size += chunk.length
    if (size > MAX_BODY) throw new Error('Body too large')
    chunks.push(chunk)
  }
  const text = Buffer.concat(chunks).toString('utf8')
  return text ? JSON.parse(text) : {}
}

export function createHandler({ getStripe }) {
  return async function handler(req, res) {
    if (req.method !== 'POST') {
      res.setHeader('Allow', 'POST')
      return res.status(405).json({ error: 'Method not allowed' })
    }

    const key = process.env.STRIPE_SECRET_KEY
    if (!key) return res.status(503).json({ error: 'Stripe not configured' })
    if (!key.startsWith('sk_test_')) return res.status(503).json({ error: 'Sandbox only: use a Stripe test key' })

    let body
    try {
      body = await readBody(req)
    } catch {
      return res.status(400).json({ error: 'Invalid request body' })
    }

    let priced
    try {
      priced = priceItems(body && body.items)
    } catch (err) {
      if (err instanceof PricingError) return res.status(400).json({ error: err.message })
      throw err
    }

    try {
      const intent = await getStripe(key).paymentIntents.create({
        amount: priced.amount,
        currency: 'usd',
        automatic_payment_methods: { enabled: true },
        description: 'KVIST demo order',
        metadata: { cart: priced.lines.map((l) => `${l.id}×${l.qty}`).join(',') },
      })
      return res.status(200).json({ clientSecret: intent.client_secret, amount: priced.amount })
    } catch (err) {
      console.error('[api] PaymentIntent create failed:', err && err.message)
      return res.status(500).json({ error: 'Payment setup failed' })
    }
  }
}

let client = null
export default createHandler({
  getStripe: (key) => (client ??= new Stripe(key)),
})

import { defineConfig, loadEnv } from 'vite'

function apiDev() {
  return {
    name: 'kvist-api-dev',
    apply: 'serve',
    configureServer(server) {
      const env = loadEnv(server.config.mode, server.config.root, '')
      for (const [k, v] of Object.entries(env)) if (process.env[k] === undefined) process.env[k] = v

      server.middlewares.use('/api', async (req, res, next) => {
        const name = (req.url || '').split('?')[0].replace(/^\/+/, '')
        if (!/^[a-z0-9-]+$/.test(name)) return next()
        let mod
        try {
          mod = await server.ssrLoadModule(`/api/${name}.js`)
        } catch {
          return next()
        }
        res.status = (code) => {
          res.statusCode = code
          return res
        }
        res.json = (obj) => {
          res.setHeader('Content-Type', 'application/json')
          res.end(JSON.stringify(obj))
          return res
        }
        try {
          await mod.default(req, res)
        } catch (err) {
          server.ssrFixStacktrace(err)
          console.error(err)
          if (!res.headersSent) res.status(500).json({ error: 'Server error' })
        }
      })
    },
  }

```js
// Fly-to-cart: clone the product image (or its placeholder box) and arc it into the header cart.
// The cart itself lives in store.js; this module animates adds and keeps the header counter in sync.
import { gsap } from 'gsap'
import { $, ensureTransformable } from './utils.js'
import { showHeader } from './nav.js'
import { cart } from './store.js'
import { PRODUCTS, MAX_QTY } from '../data/products.js'

let cartBtn = null
let countEl = null
let liveEl = null
let reducedMode = false

export function initCart({ reduced } = {}) {
  reducedMode = !!reduced
  cartBtn = $('[data-cart]')
  countEl = $('[data-cart-n]')
  liveEl = $('[data-cart-live]')
  if (!reducedMode) ensureTransformable([countEl])

  render(false)
  cart.onChange((change) => render(change.type === 'add'))

  document.addEventListener('click', (e) => {
    const btn = e.target.closest && e.target.closest('[data-add]')
    if (!btn) return
    e.preventDefault()
    addToCart(btn)
  })
}

function cartLabel() {
  const n = cart.count()
  return `Cart, ${n} item${n === 1 ? '' : 's'}`
}

function announce(msg) {
  if (!liveEl) return
  liveEl.textContent = ''
  requestAnimationFrame(() => (liveEl.textContent = msg))
}

function addToCart(btn) {
  const id = btn.dataset.id
  const product = PRODUCTS[id]
  if (!product) return
  if (cart.qtyOf(id) >= MAX_QTY) {
    announce(`${product.name}: maximum of ${MAX_QTY} per order.`)
    return
  }
  const commit = () => {
    if (cart.add(id)) announce(`Added ${product.name}. ${cartLabel()}.`)
  }

  if (reducedMode || !cartBtn) return commit()
  const card = btn.closest('.product, .lcard')
  const media = card && $('.product__media, .lcard__media', card)
  if (!media) return commit()
  showHeader()
  fly(media, commit)
}

function makeClone(media) {
  const img = $('img', media)
  const useImg = img && img.isConnected && img.complete && img.naturalWidth > 0
  const src = useImg ? img : media
  const rect = src.getBoundingClientRect()
  const cs = getComputedStyle(src)

  const clone = src.cloneNode(true)
  clone.removeAttribute('id')
  clone.setAttribute('aria-hidden', 'true')
  clone.classList.remove('is-in')
  // Styles scoped to the card won't reach a clone on <body>, so carry the essentials inline.
  Object.assign(clone.style, {
    position: 'fixed',
    left: `${rect.left}px`,
    top: `${rect.top}px`,
    width: `${rect.width}px`,
    height: `${rect.height}px`,
    margin: '0',
    zIndex: '9999',
    pointerEvents: 'none',
    opacity: '1',
    transform: 'none',
    borderRadius: cs.borderRadius,
    overflow: 'hidden',
    willChange: 'transform',
  })
  if (!useImg) {
    clone.style.background = cs.backgroundImage !== 'none' ? cs.background : '#D8CFC1'
    clone.querySelectorAll('img').forEach((n) => n.remove())
  } else {
    clone.style.objectFit = cs.objectFit
  }
  document.body.appendChild(clone)
  return { clone, rect }
}

function cartCentre() {
  const r = cartBtn.getBoundingClientRect()
  // If the header is currently slid up, aim where it will be once shown.
  const header = cartBtn.closest('header')
  const shift = header ? header.getBoundingClientRect().top : 0
  return { x: r.left + r.width / 2, y: r.top + r.height / 2 - Math.min(0, shift) }
}

function fly(media, onLand) {
  const { clone, rect } = makeClone(media)
  const to = cartCentre()
  const dx = to.x - (rect.left + rect.width / 2)
  const dy = to.y - (rect.top + rect.height / 2)

  const d = 0.9
  gsap
    .timeline({
      onComplete: () => {
        clone.remove()
        onLand()
      },
    })
    .set(clone, { transformOrigin: '50% 50%' })
    .to(clone, { x: dx, duration: d, ease: 'power1.inOut' }, 0)
    .to(clone, { y: dy, duration: d, ease: 'back.in(1.6)' }, 0)
    .to(clone, { scale: 0.1, rotation: 28, duration: d, ease: 'power2.in' }, 0)
    .to(clone, { opacity: 0, duration: 0.12, ease: 'none' }, d - 0.12)
}

/** Sync counter + label from the store; `pop` plays the add feedback. */
function render(pop) {
  const n = cart.count()
  if (countEl) countEl.textContent = String(n)
  if (!cartBtn) return
  cartBtn.classList.toggle('has-items', n > 0)
  cartBtn.setAttribute('aria-label', cartLabel())
  if (!pop || reducedMode) return

  if (countEl) {
    gsap.fromTo(countEl, { scale: 1.8 }, { scale: 1, duration: 0.9, ease: 'elastic.out(1, .4)', overwrite: 'auto' })
  }
  const svg = $('svg', cartBtn)
  if (svg) {
    gsap.fromTo(
      svg,
      { rotation: -14, transformOrigin: '50% 60%' },
      { rotation: 0, duration: 1, ease: 'elastic.out(1.2, .35)', overwrite: 'auto' },
    )
  }
}
```

// Cart drawer: list, quantity editing, subtotal, focus trap and slide-in motion.
import { gsap } from 'gsap'
import { $, $$ } from './utils.js'
import { cart } from './store.js'
import { PRODUCTS, MAX_QTY, formatPrice } from '../data/products.js'
import { lockScroll, unlockScroll } from './scroll.js'
import { closeMenu } from './nav.js'

let drawer = null
let panel = null
let scrim = null
let list = null
let empty = null
let foot = null
let subtotalEl = null
let closeBtn = null
let opener = null
let isOpen = false
let reducedMode = false
let tl = null

export function initDrawer({ reduced } = {}) {
  drawer = $('[data-drawer]')
  if (!drawer) return
  reducedMode = !!reduced
  panel = $('.drawer__panel', drawer)
  scrim = $('.drawer__scrim', drawer)
  list = $('.drawer__list', drawer)
  empty = $('.drawer__empty', drawer)
  foot = $('.drawer__foot', drawer)
  subtotalEl = $('[data-drawer-subtotal]', drawer)
  closeBtn = $('.drawer__close', drawer)

  render()
  cart.onChange(render)

  const cartBtn = $('[data-cart]')
  if (cartBtn) cartBtn.addEventListener('click', () => openDrawer())
  $$('[data-drawer-close]', drawer).forEach((el) => el.addEventListener('click', closeDrawer))
  drawer.addEventListener('keydown', onKey)
  list.addEventListener('click', onListClick)
}

/** True when the URL asked for the drawer (`?cart=open`); strips the param. */
export function consumeCartParam() {
  const params = new URLSearchParams(location.search)
  if (params.get('cart') !== 'open') return false
  params.delete('cart')
  const qs = params.toString()
  try {
    history.replaceState(null, '', location.pathname + (qs ? `?${qs}` : '') + location.hash)
  } catch {
    /* sandboxed */
  }
  return true
}

/* ---------- render ---------- */

function row({ id, qty }) {
  const p = PRODUCTS[id]
  const li = document.createElement('li')
  li.className = 'drawer__item'
  li.dataset.id = id
  li.innerHTML = `
    <img class="drawer__thumb" src="${p.image}" alt="" width="72" height="72" loading="lazy" decoding="async">
    <div class="drawer__info">
      <p class="drawer__name">${p.name}</p>
      <p class="drawer__unit">${formatPrice(p.price)}</p>
      <div class="qty" role="group" aria-label="Quantity for ${p.name}">
        <button class="qty__btn" type="button" data-step="-1" aria-label="Decrease quantity of ${p.name}"${qty <= 1 ? ' disabled' : ''}>−</button>
        <span class="qty__n">${qty}</span>
        <button class="qty__btn" type="button" data-step="1" aria-label="Increase quantity of ${p.name}"${qty >= MAX_QTY ? ' disabled' : ''}>+</button>
      </div>
    </div>
    <div class="drawer__end">
      <p class="drawer__line">${formatPrice(p.price * qty)}</p>
      <button class="drawer__remove" type="button" data-remove>Remove<span class="sr"> ${p.name}</span></button>
    </div>`
  return li
}

function render() {
  if (!list) return
  const items = cart.getItems()
  list.replaceChildren(...items.map(row))
  const has = items.length > 0
  list.hidden = !has
  foot.hidden = !has
  empty.hidden = has
  subtotalEl.textContent = formatPrice(cart.subtotal())
}

/* ---------- editing ---------- */

function onListClick(e) {
  const btn = e.target.closest('button')
  const item = btn && btn.closest('.drawer__item')
  if (!item) return
  const id = item.dataset.id

  if (btn.hasAttribute('data-remove')) {
    const next = item.nextElementSibling || item.previousElementSibling
    const nextId = next && next.dataset.id
    cart.remove(id)
    const target = nextId && $(`.drawer__item[data-id="${nextId}"] [data-remove]`, list)
    ;(target || (empty.hidden ? closeBtn : $('button', empty))).focus()
    return
  }

  const step = Number(btn.dataset.step)
  if (!step) return
  cart.setQty(id, cart.qtyOf(id) + step)
  // render() replaced the row; put focus back on the same control (or its sibling if now disabled).
  const fresh = $(`.drawer__item[data-id="${id}"]`, list)
  if (!fresh) return
  const same = $(`[data-step="${step}"]`, fresh)
  ;(same && !same.disabled ? same : $(`[data-step="${-step}"]`, fresh)).focus()
}

/* ---------- open / close ---------- */

function focusables() {
  return $$('a[href], button:not([disabled])', panel).filter((el) => !el.closest('[hidden]'))
}

function onKey(e) {
  if (e.key === 'Escape') {
    e.preventDefault()
    e.stopPropagation()
    closeDrawer()
    return
  }
  if (e.key !== 'Tab') return
  const f = focusables()
  if (!f.length) return
  const first = f[0]
  const last = f[f.length - 1]
  if (e.shiftKey && document.activeElement === first) {
    e.preventDefault()
    last.focus()
  } else if (!e.shiftKey && document.activeElement === last) {
    e.preventDefault()
    first.focus()
  }
}

export function openDrawer() {
  if (!drawer || isOpen) return
  isOpen = true
  closeMenu()
  opener = document.activeElement
  drawer.hidden = false
  lockScroll('drawer')
  if (tl) tl.kill()

  if (!reducedMode) {
    const rows = $$('.drawer__item', list)
    tl = gsap
      .timeline()
      .fromTo(scrim, { opacity: 0 }, { opacity: 1, duration: 0.4, ease: 'power2.out' }, 0)
      .fromTo(panel, { xPercent: 100 }, { xPercent: 0, duration: 0.7, ease: 'power3.out' }, 0)
    if (rows.length) {
      tl.fromTo(
        rows,
        { y: 24, opacity: 0 },
        { y: 0, opacity: 1, duration: 0.6, ease: 'power3.out', stagger: 0.06, clearProps: 'transform,opacity' },
        0.2,
      )
    }
  }
  closeBtn.focus({ preventScroll: true })
}

export function closeDrawer() {
  if (!drawer || !isOpen) return
  isOpen = false
  const done = () => {
    drawer.hidden = true
    unlockScroll('drawer')
    if (opener && opener.isConnected && opener.focus) opener.focus({ preventScroll: true })
  }
  if (tl) tl.kill()
  if (reducedMode) return done()
  tl = gsap
    .timeline({ onComplete: done })
    .to(panel, { xPercent: 100, duration: 0.45, ease: 'power3.in' }, 0)
    .to(scrim, { opacity: 0, duration: 0.35, ease: 'power2.in' }, 0.1)
}

// Checkout form rules and Stripe mapping. Pure functions, no DOM.

export const COUNTRIES = [
  { code: 'US', name: 'United States' },
  { code: 'CA', name: 'Canada' },
  { code: 'GB', name: 'United Kingdom' },
  { code: 'SE', name: 'Sweden' },
  { code: 'NO', name: 'Norway' },
  { code: 'DK', name: 'Denmark' },
  { code: 'DE', name: 'Germany' },
  { code: 'NL', name: 'Netherlands' },
  { code: 'PH', name: 'Philippines' },
  { code: 'AU', name: 'Australia' },
]

const MAX_LEN = 120
const filled = (v) => v.length > 0 && v.length <= MAX_LEN

const RULES = {
  email: [(v) => /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/.test(v) && v.length <= MAX_LEN, 'Enter an email like name@example.com'],
  name: [filled, 'Enter your full name'],
  line1: [filled, 'Enter your street address'],
  line2: [(v) => v.length <= MAX_LEN, 'Keep this under 120 characters'],
  city: [filled, 'Enter your city'],
  postal: [(v) => /^[A-Za-z0-9][A-Za-z0-9 -]{1,8}[A-Za-z0-9]$/.test(v), 'Enter a valid postal code'],
  country: [(v) => COUNTRIES.some((c) => c.code === v), 'Choose a country'],
}

const clean = (values, key) => String((values && values[key]) ?? '').trim()

/** Returns { field: message } for every invalid field; {} when the form is valid. */
export function validate(values) {
  const errors = {}
  for (const [key, [ok, message]] of Object.entries(RULES)) {
    if (!ok(clean(values, key))) errors[key] = message
  }
  return errors
}

export function toShipping(values) {
  const address = {
    line1: clean(values, 'line1'),
    city: clean(values, 'city'),
    postal_code: clean(values, 'postal'),
    country: clean(values, 'country'),
  }
  const line2 = clean(values, 'line2')
  if (line2) address.line2 = line2
  return { name: clean(values, 'name'), address }
}

export const orderRef = (intentId) => `KV-${String(intentId).slice(-8).toUpperCase()}`

export function resultView(status) {
  if (status === 'succeeded') return 'success'
  if (status === 'processing' || status === 'requires_capture') return 'processing'
  return 'failed'
}

/* ---------- views ---------- */

function show(name) {
  if (current === name) return
  current = name
  $$('[data-view]', page).forEach((v) => (v.hidden = v.dataset.view !== name))
  reveal($(`[data-view="${name}"]`, page))
  ScrollTrigger.refresh()
}

function reveal(view) {
  if (!view || reducedMode) return
  const lines = $$('.co__h .line > span', view)
  const blocks = $$('[data-rise]', view)
  gsap.fromTo(
    lines,
    { yPercent: 110, rotation: 2, transformOrigin: '0% 100%' },
    { yPercent: 0, rotation: 0, duration: 1.1, ease: 'power4.out', stagger: 0.1 },
  )
  gsap.fromTo(
    blocks,
    { y: 40, opacity: 0 },
    { y: 0, opacity: 1, duration: 1, ease: 'power3.out', stagger: 0.08, delay: 0.15, clearProps: 'transform,opacity' },
  )
}

function startForm({ notice, values } = {}) {
  if (!cart.count()) return show('empty')
  show('form')
  renderSummary()
  if (values) prefill(values)
  if (notice) showPayError(notice)
  cart.onChange(onCartChange)

  if (!PK) return showNotice('Stripe isn’t configured yet. Add your test keys to .env and restart the dev server.')
  if (!PK.startsWith('pk_test_')) return showNotice('Sandbox only: use a Stripe test publishable key (pk_test_…).')
  setupPayment()
}

function onCartChange() {
  if (current === 'done') return

  show('form')
  renderSummary()

  clearTimeout(refreshTimer)
  if (PK.startsWith('pk_test_')) refreshTimer = setTimeout(setupPayment, 300)
}

function prefill(values) {
  for (const [k, v] of Object.entries(values)) {
    const input = form.elements.namedItem(k)
    if (input && typeof v === 'string') input.value = v

function setFieldError(name, message) {
  const input = form.elements.namedItem(name)
  const err = $(`#e-${name}`, form)
  if (input) input.setAttribute('aria-invalid', message ? 'true' : 'false')
  if (err) err.textContent = message || ''
}

function bindForm() {
  if (!form) return
  form.addEventListener('submit', onSubmit)
  // Once a field has been flagged, re-check it as the user fixes it.
  form.addEventListener('input', (e) => {
    const name = e.target.name
    if (!name || e.target.getAttribute('aria-invalid') !== 'true') return
    setFieldError(name, validate(readValues())[name])
  })
  const retry = $('[data-pay-retry]', page)
  if (retry) retry.addEventListener('click', setupPayment)
}

  busy = on

  ready = on

function showNotice(text, { retry = false } = {}) {

  $('[data-pay-notice-text]', box).textContent = text
  $('[data-pay-retry]', box).hidden = !retry
  box.hidden = false
  setReady(false)
}

function hideNotice() {
  $('[data-pay-notice]', page).hidden = true
}

function showPayError(text) {
  payError.textContent = text || ''
}

async function createIntent(items) {
  const res = await fetch('/api/create-payment-intent', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ items }),
  })
  let data = {}
  try {
    data = await res.json()
  } catch {
    /* non-JSON error page */
  }
  if (!res.ok || !data.clientSecret) throw new Error(data.error || `Payment setup failed (${res.status})`)
  return data
}

async function setupPayment() {
  const token = ++intentToken
  setReady(false)
  hideNotice()
  try {
    stripe = stripe || (await loadStripe(PK))
    if (!stripe) throw new Error('Stripe.js could not load. Check your connection.')
    const { clientSecret, amount } = await createIntent(cart.getItems())
    if (token !== intentToken) return // a newer cart change superseded this one

    if (paymentEl) paymentEl.destroy()
    elements = stripe.elements({ clientSecret, appearance: APPEARANCE, fonts: FONTS })
    paymentEl = elements.create('payment', { layout: 'tabs' })
    paymentEl.on('ready', () => {
      if (token === intentToken) setReady(true)
    })
    paymentEl.mount('#payment-element')
    intentAmount = amount
    updatePayLabel()
  } catch (err) {
    if (token !== intentToken) return
    showNotice(err.message || 'Payment setup failed.', { retry: true })
  }
}

function saveSnapshot() {
  try {
    sessionStorage.setItem(SNAPSHOT_KEY, JSON.stringify({ items: cart.getItems(), values: readValues() }))
  } catch {
    /* ignore */
  }
}

function readSnapshot() {
  try {
    return JSON.parse(sessionStorage.getItem(SNAPSHOT_KEY) || 'null')
  } catch {
    return null
  }
}

async function onSubmit(e) {
  e.preventDefault()
  if (busy || !ready) return
  showPayError('')

  const values = readValues()
  const errors = validate(values)
  Object.keys(Object.fromEntries(new FormData(form))).forEach((k) => setFieldError(k, errors[k]))
  const firstBad = Object.keys(errors)[0]
  if (firstBad) {
    form.elements.namedItem(firstBad).focus()
    return
  }

  setBusy(true)
  saveSnapshot()
  const { error } = await stripe.confirmPayment({
    elements,
    confirmParams: {
      return_url: `${location.origin}${location.pathname}`,
      receipt_email: values.email.trim(),
      shipping: toShipping(values),
    },
  })
  // Only reached when confirmation fails before a redirect.
  setBusy(false)
  const userFacing =
    error &&
    (error.type === 'card_error' ||
      error.type === 'validation_error' ||
      error.code === 'payment_intent_authentication_failure')
  showPayError(userFacing ? error.message : 'Something went wrong with the payment. Please try again.')
}

/* ---------- return from Stripe ---------- */

async function handleReturn(clientSecret) {
  if (!PK.startsWith('pk_test_')) return startForm()
  try {
    stripe = await loadStripe(PK)
    const { paymentIntent, error } = await stripe.retrievePaymentIntent(clientSecret)
    const view = error || !paymentIntent ? 'failed' : resultView(paymentIntent.status)
    const snap = readSnapshot()

    if (view === 'failed') {
      history.replaceState(null, '', location.pathname)
      return startForm({ notice: 'That payment didn’t go through. Try another card.', values: snap && snap.values })
    }
    // Keep the URL so a refresh shows this result again.
    cart.clear()
    renderDone(view, paymentIntent, snap)
  } catch (err) {
    console.error('[KVIST] Could not read payment result.', err)
    history.replaceState(null, '', location.pathname)
    startForm({ notice: 'We couldn’t confirm that payment. Please try again.' })
  }
}

function renderDone(view, pi, snap) {
  $('[data-done-ref]', page).textContent = `Order ${orderRef(pi.id)}`
  $('[data-done-title]', page).textContent = view === 'success' ? 'Thank you' : 'Almost there'
  const email = pi.receipt_email || (snap && snap.values && snap.values.email) || ''
  $('[data-done-lead]', page).textContent =
    view === 'success'
      ? `Your test payment went through. In a real shop, a confirmation would be on its way to ${email || 'your inbox'}.`
      : 'Your payment is processing. This page will show the result once Stripe confirms it — refresh in a moment.'

  const ship = pi.shipping
  const addr = ship && ship.address
  $('[data-done-ship]', page).textContent = ship
    ? [ship.name, addr.line1, addr.line2, `${addr.city} ${addr.postal_code}`, COUNTRIES.find((c) => c.code === addr.country)?.name || addr.country]
        .filter(Boolean)
        .join('\n')
    : '—'
  $('[data-done-total]', page).textContent = formatPrice(pi.amount)

  const list = $('[data-done-items]', page)
  const items = (snap && Array.isArray(snap.items) ? snap.items : []).filter((l) => PRODUCTS[l.id])
  list.replaceChildren(
    ...items.map(({ id, qty }) => {
      const li = document.createElement('li')
      const img = document.createElement('img')
      img.src = PRODUCTS[id].image
      img.alt = `${PRODUCTS[id].name}${qty > 1 ? ` × ${qty}` : ''}`
      img.width = 88
      img.height = 88
      li.appendChild(img)
      return li
    }),
  )
  list.hidden = !items.length

  show('done')
  if (!reducedMode && items.length) {
    gsap.fromTo(
      $$('li', list),
      { y: 60, opacity: 0, rotation: -6 },
      { y: 0, opacity: 1, rotation: 0, duration: 0.9, ease: 'back.out(1.7)', stagger: 0.08, delay: 0.35 },
    )
  }
}
